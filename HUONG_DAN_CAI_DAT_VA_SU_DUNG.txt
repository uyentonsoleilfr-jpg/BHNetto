================================================================================
          HƯỚNG DẪN CÀI ĐẶT & SỬ DỤNG PHIẾU BẢO HÀNH NETTO PRIME (2K)
================================================================================

Bộ công cụ tạo phiếu cam kết hoàn tiền 100% tự động dành cho Telesales & CSKH.
Ứng dụng chạy độc lập 100%, không cần cài thêm phần mềm hay database phức tạp.

--------------------------------------------------------------------------------
1. CẤU TRÚC THƯ MỤC TRONG GÓI:
--------------------------------------------------------------------------------
- CHAY_NGAY.bat                : Nhấp đúp chuột để mở ứng dụng ngay trên trình duyệt.
- index.html                   : File ứng dụng chính (chuẩn web để chạy hoặc deploy).
- APP_PHIEU_BAO_HANH_NETTO.html: Bản sao ứng dụng với tên gọi trực quan.
- assets/                      : Chứa phôi ảnh gốc và phôi ảnh 2K độ phân giải cao.
- HUONG_DAN_CAI_DAT_VA_SU_DUNG.txt : Tài liệu này.

--------------------------------------------------------------------------------
2. CÁCH 1: DÙNG NGAY OFFLINE TRÊN MÁY TÍNH / LAPTOP (DÀNH CHO SALE)
--------------------------------------------------------------------------------
- Bước 1: Mở thư mục "Phieu_Bao_Hanh_Netto".
- Bước 2: Nhấp đúp chuột vào file "CHAY_NGAY.bat" (hoặc nhấp đúp vào file "index.html").
- Bước 3: Trình duyệt (Chrome, Cốc Cốc, Edge) sẽ mở giao diện tạo phiếu.
- Bước 4: Sale gõ tên khách hàng, SĐT, chọn loại sâu và cây trồng.
- Bước 5: Bấm nút "SAO CHÉP ẢNH (DÁN ZALO)" -> Sang Zalo của khách bấm Ctrl + V để gửi.

--------------------------------------------------------------------------------
3. CÁCH 2: SETUP LÊN WEB ONLINE (GITHUB PAGES / HOSTING / NETLIFY / VERCEL)
--------------------------------------------------------------------------------
Để toàn bộ đội ngũ Sale truy cập chung qua 1 đường link (trên cả điện thoại di động):
- Với GitHub Pages: Tạo repo mới -> Tải toàn bộ các file trong thư mục này lên -> Vào Settings > Pages > Chọn nhánh main > Save -> Nhận link web miễn phí.
- Với Hosting / cPanel: Tải toàn bộ thư mục này vào public_html (hoặc thư mục con).
- Với Netlify / Vercel: Kéo thả trực tiếp cả thư mục vào trang Netlify Drop là xong trong 10 giây.

--------------------------------------------------------------------------------
4. ĐIỂM NỔI BẬT VỀ KỸ THUẬT:
--------------------------------------------------------------------------------
- Độ phân giải: Siêu nét 2K (2048 x 1320 px) chuẩn in ấn 300 DPI.
- Phôi ảnh được nhúng trực tiếp bằng Base64 bên trong HTML nên không bao giờ sợ mất đường dẫn ảnh khi di chuyển file.
- Hỗ trợ co giãn font chữ tự động (Auto-fit text) chống tràn viền.
- Clipboard API: Sao chép ảnh trực tiếp vào bộ nhớ tạm 1 chạm.
