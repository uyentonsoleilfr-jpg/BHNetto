================================================================================
          HƯỚNG DẪN ĐƯA LÊN GITHUB PAGES TẠO LINK WEB ONLINE (2 PHÚT)
================================================================================

Sau khi up lên GitHub Pages, bạn sẽ có ngay 1 đường link web (dạng https://username.github.io/ten-repo/) 
để toàn bộ nhân viên Sale mở trên điện thoại hay máy tính đều dùng chung được.

--------------------------------------------------------------------------------
BƯỚC 1: TẠO KHO LƯU TRỮ (REPOSITORY) MỚI TRÊN GITHUB
--------------------------------------------------------------------------------
1. Truy cập https://github.com và đăng nhập tài khoản.
2. Bấm vào nút màu xanh lá "New" ở góc trái (hoặc bấm dấu "+" ở góc trên bên phải -> chọn "New repository").
3. Điền thông tin:
   - Repository name: Điền tên tiếng Việt không dấu (Ví dụ: phieu-bao-hanh-netto)
   - Chọn chế độ: Public (bắt buộc chọn Public để dùng tính năng web miễn phí).
4. Bấm nút xanh "Create repository" ở dưới cùng.

--------------------------------------------------------------------------------
BƯỚC 2: TẢI CÁC FILE TRONG THƯ MỤC NÀY LÊN
--------------------------------------------------------------------------------
1. Ở trang mới hiện ra, bấm vào dòng chữ: "uploading an existing file".
2. Kéo thả toàn bộ các file trong thư mục "Phieu_Bao_Hanh_Netto" (gồm index.html và thư mục assets) vào ô upload trên trình duyệt.
3. Đợi các file tải lên xong -> Kéo xuống dưới cùng bấm nút xanh "Commit changes".

--------------------------------------------------------------------------------
BƯỚC 3: BẬT TÍNH NĂNG WEB (GITHUB PAGES)
--------------------------------------------------------------------------------
1. Tại trang Repository vừa up xong, bấm vào tab "Settings" (hình bánh răng ở góc trên).
2. Ở thanh menu bên trái, tìm và bấm vào mục "Pages".
3. Tại phần "Build and deployment":
   - Mục Branch: Đổi từ "None" sang "main" (hoặc "master").
   - Thư mục bên cạnh giữ nguyên là "/(root)".
4. Bấm nút "Save".

--------------------------------------------------------------------------------
BƯỚC 4: NHẬN LINK WEB VÀ GỬI CHO SALE
--------------------------------------------------------------------------------
- Chờ khoảng 1 - 2 phút, sau đó bấm F5 tải lại trang Settings > Pages.
- Ở đầu trang sẽ xuất hiện thông báo màu xanh kèm đường link web chính thức:
  👉 https://[ten-tai-khoan].github.io/phieu-bao-hanh-netto/
- Copy link này gửi vào nhóm Zalo công ty để mọi người cùng sử dụng!
